# GitHub User Finder

**Автор: Кошкидько Кирилл Александрович** 

**Сделан: 4 мая**

GitHub User Finder - это десктопное приложение с графическим интерфейсом для поиска пользователей GitHub. Приложение позволяет искать пользователей, просматривать их профили и сохранять избранных пользователей в локальное хранилище (JSON).

## Функциональность

- 🔍 Поиск пользователей GitHub по логину
- 📋 Отображение списка найденных пользователей
- ⭐ Добавление пользователей в избранное
- ❌ Удаление пользователей из избранного
- 👤 Просмотр детальной информации о пользователе
- 💾 Сохранение избранных пользователей в JSON файл
- 🎨 Интуитивно понятный графический интерфейс
- ✅ Валидация ввода (поле поиска не может быть пустым)

## Установка и запуск

### Системные требования

- Python 3.7 или выше
- Интернет-соединение (для работы с GitHub API)
- Операционная система: Windows, macOS или Linux

## Описание

GitHub User Finder - это десктопное приложение с графическим интерфейсом для поиска пользователей GitHub. Приложение позволяет искать пользователей, просматривать их профили и сохранять избранных пользователей в локальное хранилище.

## Функциональность

- 🔍 Поиск пользователей GitHub по логину
- 📋 Отображение списка найденных пользователей
- ⭐ Добавление пользователей в избранное
- ❌ Удаление пользователей из избранного
- 👤 Просмотр детальной информации о пользователе
- 💾 Сохранение избранных пользователей в JSON файл
- 🎨 Интуитивно понятный графический интерфейс
